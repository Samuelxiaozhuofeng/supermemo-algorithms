# 任务：SuperMemo 20 第二轮实测（文章间隔序列 + 自动推迟）

你在 Windows 云电脑上用 computer use 操作 SuperMemo 20，接着上一轮的测试集合 `C:\SMTest\test1` 继续做。目的是**观察原版的真实行为**：按剧本操作，把界面上的数字原样抄下来。不需要理解算法，也不要推算任何数值。

## 分工：系统日期由用户来改

**你不碰系统时间和任何系统设置。** 每一轮都这样走：

1. 你做完本轮的事，用 **File → Exit** 关掉 SuperMemo，然后告诉用户：「请把日期调到 YYYY-MM-DD 12:00」。日期按下文每一轮的规则算出来。
2. 用户改好后会回复「日期已调到 …」。
3. 你重新打开 SuperMemo，确认打开的是 `C:\SMTest\test1`，再看一眼 Windows 右下角的日期是不是用户说的那天。不对就停下来报告。

## 铁律

1. 只动 `C:\SMTest\test1` 这个集合。不删任何元素，包括上一轮误建的两个空 topic（#5、#6），它们也照常参加学习。
2. 只抄界面上实际显示的值，原样照抄，保留全部小数位。看不到的写 `null` 并说明原因，不估算、不补全。
3. 学习时对 topic 只按 **Next**。不打分、不摘录，不按 Postpone、Later today、Reschedule、Forget、Dismiss。
4. 出现注册、激活、购买、登录、联网下载的弹窗，或要求管理员密码，或任何你没把握的对话框：截图，原样抄下文字，停下来报告。**SuperMemo 弹出的跟推迟有关的提示，原样抄下文字后点默认按钮。**
5. 某一步做不下去：截图，写清楚卡在哪，跳过这一步继续。

## 读数方法（和上一轮相同）

选中元素，按 **Ctrl+Shift+P** 打开 Element parameters。要抄的字段：元素号（#）、标题、Priority、A-Factor、Interval、Last repetition、Next repetition、Repetitions、Postpones（有就抄），以及 **History 的最后两行**（原样照抄，例如 `1:0 10月19 2026 09:03:27 Auto interval1`）。

## S2 文章的复习间隔（4 + 1 轮）

**开始前：** 打开 Learn → Postpone，**取消勾选 Auto-postpone**，读回确认已经是不勾状态。（S2 做完之后的 S5 会再打开。）

**第 1–4 轮（每轮都一样）：**
- 点 Learn。当天到期的每一篇（Learn 会一篇接一篇给出）：先按 Next，**紧接着读它的参数**，然后再继续下一篇，直到 Learn 说今天没有要复习的了。
- **只在第 1 轮：** 学到 #6 时，先不按 Next，按一次 **Ctrl+Shift+Up**，读 Priority；再按一次 **Ctrl+Shift+Down**，再读 Priority；然后照常按 Next 并读数。
- 本轮结束后，用 View → Priority queue（或 Browser）看全部元素的 Next repetition，取**最早的那个日期**，作为下一轮的日期。

**第 5 轮（看逾期怎么算）：** 下一轮的日期 = 最早的 Next repetition **再往后加 3 天**。其余做法和第 1–4 轮相同。

## S5 自动推迟

**第 0 天（S2 第 5 轮做完后，日期不变）：**
1. 新建 15 篇 topic，标题 A01–A15，正文如下（正文要完全一样，方便对比）：
   - A01–A05：**正文留空**，只有标题；
   - A06–A15：正文是这 100 个字符（一字不差）：`abcdefghij` 连续重复 10 次。
2. **每建一篇，立刻读一次参数**（这批读数也用来看新文章的 A-Factor 有没有随机成分）。
3. 用 Element parameters 把 Priority 依次改成：A01=2、A02=4、A03=6、A04=8、A05=10、A06=15、A07=20、A08=30、A09=40、A10=50、A11=60、A12=70、A13=80、A14=90、A15=99。改完把 15 篇都再读一次。
4. 打开 Learn → Postpone，**勾上 Auto-postpone**。再把 Postpone 对话框 Parameters、Adjust、Scope 三页各截一张图，原样抄下所有值（**不要改**），抄完点 **Cancel** 关掉。**绝不点 OK**，点 OK 会立刻手动推迟一次，整轮作废。
5. File → Exit，请用户把日期调到「今天 + 9 天」的 12:00。**不要超过 9 天**。

**第 9 天：**
1. 打开 SuperMemo，点 **Learn**，抄下弹出的所有提示的全文。**不复习任何东西**：Learn 一给出第一个元素就关掉学习窗口。
2. 把 A01–A15 全部读一次。其他元素有 Postpones 不为 0 的，也读一次。
3. 如果 A01–A15 的 Next repetition 全都没有变化（还是第 1 天，也就是已经逾期），说明没有推迟。这时不要手动推迟，在报告里写明就收工。
