# 任务：在 SuperMemo 20 里做实测，抄下排期和优先级的读数

你在一台 Windows 云电脑上，用 computer use 操作已经打开的 SuperMemo 20。目的是**观察原版的真实行为**：按下面的剧本操作，每一步把界面上显示的数字原样抄下来。你**不需要**理解算法，也**不要**去推算任何数值。

## 铁律

1. **只用全新的测试集合。** File → New collection，建在 `C:\SMTest\test1`。如果 SuperMemo 打开的是别的集合，先关掉，不要改动它的任何内容。
2. **只抄界面上实际显示的值。** 原样照抄，保留全部小数位。看不到的值写 `null`，并说明原因，不许估算、不许补全。
3. **每次读数都截一张图**，存到 `C:\SMTest\shots\`，文件名用 `场景-步骤.png`，例如 `S2-03.png`。
4. **日期只往前调，绝不往回调。** 改系统时间时，一律把钟点设在 **中午 12:00**，避开日切点。
5. **出现以下任一情况，立刻停下来报告，不要自己处理：** 注册、激活、购买、登录、联网下载的弹窗；要求管理员密码；或者任何你没把握的对话框。
6. 除了 SuperMemo 和下面点名的系统设置，**不要碰别的程序**。
7. 某一步做不下去（菜单找不到、界面和描述对不上）：先截图，写清楚卡在哪，跳过这一步继续，不要硬猜。

## 准备工作（P）

- **P1. 关掉自动对时：** 设置 → 时间和语言 → 日期和时间 → 关闭「自动设置时间」。把系统时间设为 **今天 12:00**，记下这个日期，作为第 0 天。
- **P2. 建集合：** 新建集合 `C:\SMTest\test1`。如果新集合里自带了元素，记下有几个、各自的标题。
- **P3. 抄设置：** 打开 Tools → Options（或 Toolkit → Options），找到下面这些设置，**原样抄下当前值，不要修改**：
  - Midnight shift
  - Auto-postpone 的开关
  - Postpone 对话框里的各项默认值，包括 Item delay、Topic delay、Priority (%)，以及上限 / 下限天数
  - Repetition sorting / Auto-sort 的三个滑杆
- **P4. 怎么读一个元素：** 选中元素后打开 **Element parameters**（快捷键一般是 Ctrl+Shift+P）。如果那里看不到，就用 Learn / View 菜单里的 **Element data**（或 Statistics → Element data）。需要抄的字段有：元素号（#，标题栏里有）、类型（topic / item）、Priority（%）、A-Factor、Interval、Last repetition、Next repetition、Repetitions、Postpones（有就抄）、Status。
  **先在 P2 的任一元素上（没有就先建一篇）完整读一次，确认这些字段都在哪里显示，之后每次都用同一种读法。**

## 场景（按顺序做；做到 S5 前如果时间不够，先交 S1–S4 的结果）

**S1 新文章的初始值**
- 用 Add → New topic（或 Ctrl+N 等新建文章的方式）建 3 篇文章：T1、T2、T3。正文分别粘贴 200 字、200 字、2000 字的任意英文（可以用 lorem ipsum）。
- 每建一篇，立刻读一次它的参数。

**S2 文章的复习间隔（最重要）**
- 第 0 天：用 Learn 学一遍，学到 T1、T2、T3 时，每篇都点 **Next**（不打分，也不做摘录）。每篇点完立刻读参数。
- 接着循环 4 轮：把系统日期调到这三篇里**最早的 Next repetition 那天**的 12:00 → 重新 Learn → 对当天到期的每篇点 Next 并读数。每篇文章要拿到**至少 5 次复习**的读数，每次都要记下当天的日期。

**S3 摘录**（新开一篇 T4，正文 2000 字，之后不再动它）
- 先读一次 T4 的参数。
- 在 T4 里选一段 **正好 50 个字符** 的文字，按 **Alt+X** 摘录。然后先读 T4（父文章），再读新生成的摘录 E1。
- 再选一段 **正好 500 个字符** 的文字，按 Alt+X，读 T4 和新摘录 E2。
- 再选一段文字，按 **Alt+Shift+X**。把弹出的对话框截图，**不要改里面的任何值**，直接点 OK。读 T4 和新摘录 E3。
- 摘录用的文字原样贴进报告，好让我核对字符数。

**S4 优先级的位置与取整**
- 把集合里所有元素按优先级排好（Browser 里按 Priority 排序），抄下总数 N，以及每个元素的元素号、Priority（%）、排第几位。
- 找一个排在中间的元素，在 Element parameters 里把 Priority 手动改成 **50**，读回它显示的 Priority 和新的排位。
- 选中任一篇文章，在学习窗口按 **Ctrl+Shift+Up** 一次，读 Priority；再按 **Ctrl+Shift+Down** 一次，再读。

**S5 自动推迟**（这一步用时最长）
- 另建 **15 篇** 文章 A01–A15，正文随意。把它们的 Priority 依次设为 2、4、6、8、10、15、20、30、40、50、60、70、80、90、99。
- 第 0 天先对这 15 篇各 Learn 一次、点 Next，让它们都有 Next repetition。全部读一次数。
- 打开 Auto-postpone，**其他设置保持默认**。如果默认已经是开着的，就不用动。
- 把日期往后调到 **比这 15 篇里最晚的 Next repetition 还晚 5 天**，这样它们全部逾期。
- **先关掉 SuperMemo，再重新打开**，然后点 Learn，让自动推迟在开始学习时运行。不要复习任何东西。
- 把 A01–A15 全部重新读一次数，同时抄下 Learn 开始时弹出的任何提示。
- 如果什么都没被推迟，就用 Browser 选中 A01–A15，手动执行 **Postpone**：先把对话框截图，用默认值点 OK，然后全部再读一次数。

## 交付

1. 所有读数写到 `C:\SMTest\results.jsonl`，**一行一条 JSON**，字段固定为：
   `{"scenario":"S2","step":"03","sys_date":"YYYY-MM-DD","action":"T1 点 Next 之后","el":"#12","title":"T1","type":"topic","priority":"…","afactor":"…","interval":"…","last_rep":"…","next_rep":"…","reps":"…","postpones":"…","status":"…","shot":"S2-03.png","note":"…"}`
   所有数值都写成**字符串**，原样保留界面上的格式和小数位。
2. P3 抄到的设置，作为一条 `"scenario":"P3"` 记录写进同一个文件。
3. 最后把 `results.jsonl` 的**全部内容**贴进你给我的回复，再附一段 ≤200 字的说明：哪些场景做完了、哪些卡住了（卡在哪）、界面和本提示词描述不一致的地方。
4. 收尾时**不要**把系统时间改回去，也不要删除测试集合。
